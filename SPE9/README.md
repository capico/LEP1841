# SPE Ninth Comparative Solution Project
The provided files correspond to the simulation described in *Ninth Comparative Solution Project: A Reexamination of Black-Oil Simulation*, by J.E. Killough (SPE-29110-MS, 1995, https://doi.org/10.2118/29110-MS). The study provides a reexamination of black-oil simulation based on a model of moderate size (9,000 cells) and with a high degree of heterogeneity provided by a geostatistically-based permeability field. As an additional complication, the water-oil capillary pressure exhibits a discontinuity, which can lead to difficulties in Newton Raphson convergence for cases in which water saturations are changing significantly. These files contain a corner-point adaptation of the original block-centered model, tailored for OPM Flow.

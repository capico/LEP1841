# SPE First Comparative Solution Project
This simulation is based on the data given in 'Comparison of Solutions to a Three-Dimensional Black-Oil Reservoir Simulation Problem' by Aziz S. Odeh, Journal of Petroleum Technology, January 1981, SPE-9723-PA (https://doi.org/10.2118/9723-PA). This benchmark study compares solutions to a 3D black-oil problem conducted across seven different simulators.

- Case 1 - Bubble-point (saturation) pressure is constant with a value equal to the original value (DRSDT = 0).
- Case 2 - The saturation pressure varies with gas saturation; i.e., it is a variable saturation pressure case (DRSDT = infinity).

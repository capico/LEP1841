# Tutorial E100 e OPM Flow
Esta pasta contém o material de apoio para a oficina de introdução aos simuladores de reservatório E100 e OPM Flow. Os exercícios propostos são baseados no artigo SPE-9723-PA (https://doi.org/10.2118/9723-PA).

A documentação do simulador OPM Flow e da ferramenta de pós-processamento ResInsight está disponível nas seguintes páginas:
 https://opm-project.org/
 https://resinsight.org/
